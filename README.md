# Meu Pitch

Aplicação web que conecta startups a entusiastas e potenciais parceiros. Startups podem cadastrar suas empresas e áreas de atuação; entusiastas podem informar seus interesses e encontrar empresas relacionadas. O projeto também inclui recursos de PWA e Push Notifications.

## Requisitos

- Node.js e npm
- MongoDB em execução local na porta `27017` (feature inacessível)

## Como executar

Na pasta do projeto, instale as dependências e inicie o servidor:

```bash
npm i
node servidor.js
```

Acesse [http://localhost:4000](http://localhost:4000). O servidor utiliza o banco `Startups` no MongoDB.
